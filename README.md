# Информационная система «Библиотека»

Учебный проект на платформе «1С:Предприятие» для автоматизации работы библиотеки.

Программа предназначена для учёта книг и их экземпляров, регистрации читателей и оформления библиотечных операций.

## Возможности программы

- Ведение справочников книг, авторов, жанров, издательств и мест хранения.
- Учёт отдельных экземпляров по инвентарным номерам.
- Регистрация читателей и хранение их контактных данных и фотографий.
- Оформление поступления, выдачи и списания книг.
- Полный и частичный возврат книг.
- Продление срока выдачи и бронирование.
- Поиск книг и читателей, контроль состояния экземпляров.
- Отчёты по книгам на руках, задолженности, истории операций и состоянию фонда.
- Разделение прав администратора, библиотекаря, специалиста по фонду и руководителя.
- Формирование читательского билета и карточки книги по редактируемым макетам.

## Реализация

Используются управляемые формы, встроенный язык 1С, запросы, регистры накопления и система компоновки данных (СКД).

Данные о фонде и книгах на руках хранятся в регистрах «КнижныйФонд» и «ВыданныеКниги». При частичном возврате документ учитывает только выбранные экземпляры, а остальные остаются на руках у читателя.

В настройках можно изменять сроки выдачи и бронирования, допустимое количество книг на руках и число продлений.

## Запуск

Проект проверялся на платформе «1С:Предприятие» версии 8.5.1.1343.

1. Создать новую пустую файловую информационную базу.
2. Открыть её в Конфигураторе.
3. Выбрать «Администрирование → Загрузить информационную базу».
4. Указать файл [Библиотека.dt](Библиотека.dt).
5. Запустить базу в режиме «1С:Предприятие».

Загрузка `.dt` заменяет содержимое выбранной базы, поэтому для запуска проекта следует использовать отдельную новую базу.

Пользователи демонстрационной базы: `Администратор`, `Библиотекарь1`, `Фонд1`, `Руководитель`. Пароли пустые. В базе используются демонстрационные контактные данные и условные изображения.

## Состав проекта

- `src` — исходники конфигурации в формате XML и BSL.
- `Библиотека.dt` — заполненная демонстрационная база.
- `README.md` — описание проекта и порядок запуска.

Формы, печатные макеты и схемы отчётов доступны для редактирования в Конфигураторе.
